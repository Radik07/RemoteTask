# RemoteTask
iOS app built with SwiftUI and MVVM to practice async/await networking and clean architecture

## Overview
RemoteTasks is a simple iOS application that displays a list of tasks
fetched from a remote API. The purpose of this app is to practice
clean architecture, async/await networking, and state management

## Features
- Fetch tasks from a remote API
- Loading, error, and empty states
- Task detail view
- Pull to refresh

## Architecture
The app follows the MVVM architecture pattern to separate UI logic
from business logic

## Technologies
- Swift
- SwiftUI
- async/await
- REST API

- Local persistence
